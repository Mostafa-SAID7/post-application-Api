Introduction

PostAPI is a RESTful API built with ASP.NET Core 8 following Clean Architecture principles. All requests and responses use JSON.

ℹ All endpoints are prefixed with /api. Interactive documentation is available at Swagger UI.
Base URL
// Development http://localhost:5000/api // Example: get all posts GET http://localhost:5000/api/posts
Error Responses

All errors follow a consistent JSON shape.

400 Validation Error
{ "errors": { "Title": ["Title is required."] } }
404 Not Found
{ "type": "EntityNotFoundException", "message": "Post with Id ... was not found." }
📝 Posts
GET
/api/posts
Returns all non-deleted posts.
200
{ "items": [ { "id": "uuid", "title": "Post Title", "content": "..." } ] }
GET
/api/posts/search
Search with filters, sorting, and pagination.
200
Query Parameters
Param Type Description
searchTermstringFull-text search in title / content
categoryIdguidFilter by category
tagIdsguid[]Filter by one or more tags
createdAfterdatetimeFilter posts created after date
createdBeforedatetimeFilter posts created before date
minViewCountintMinimum view count threshold
sortBystringField to sort by (default: created)
sortDirection0 | 10 = ascending, 1 = descending
pageNumberintPage number (default: 1)
pageSizeintItems per page, max 100 (default: 10)
GET
/api/posts/{id}
Get a single post by GUID.
200
POST
/api/posts
Create a new post. Slug is auto-generated from the title.
201
{ "title": "My First Post", // required, max 200 "content": "Full post body...", // required, min 10 "summary": "Short summary", // optional "categoryId": "uuid", // optional "tagIds": ["uuid", "uuid"] // optional }
PUT
/api/posts/{id}
Update a post. Replaces title, content, summary, category, and tags.
200
DEL
/api/posts/{id}
Soft-delete a post (sets IsDeleted = true).
204
🗂 Categories
GET
/api/categories
Get all categories. Use ?rootOnly=true for top-level only, ?parentCategoryId=uuid for subcategories.
200
GET
/api/categories/{id}
Get a single category by GUID.
200
POST
/api/categories
Create a category. Name must be unique. Parent categories supported for hierarchy.
201
{ "name": "Technology", // required, max 100 "description": "Tech news", // optional, max 500 "parentCategoryId": "uuid" // optional — creates hierarchy }
PUT
/api/categories/{id}
Update name, description, or parent. Circular hierarchy is rejected.
200
DEL
/api/categories/{id}
Soft-delete a category.
204
🏷 Tags
GET
/api/tags
Get all tags. Use ?popularOnly=true&take=10 to get the most-used tags sorted by Count.
200
GET
/api/tags/{id}
Get a single tag by GUID.
200
POST
/api/tags
Create a tag. Name must be unique (case-insensitive). Slug is auto-generated.
201
{ "name": "dotnet", // required, max 50 "description": "All .NET posts" // optional, max 300 }
PUT
/api/tags/{id}
Update a tag's name or description. Slug is not changed on update.
200
DEL
/api/tags/{id}
Soft-delete a tag.
204
